x86 PC in a browser tab

Boot your own disk images. No install.

Upload an .img or .iso and it boots in a full x86 machine compiled to WebAssembly. Disks stay on storage and are read sector by sector, so a 1.5 GB XP image or an 8 GB Linux disk runs on a Chromebook without exhausting memory.

What's inside

Made for big disks and small laptops.

The emulator runs in its own worker thread and keeps disk images out of RAM, so the tab stays responsive.

  • 01

    Zero-heap disk access

    Images are copied into the browser's private file system in chunks. The emulator reads and writes 512-byte sectors directly on that file through a small reused buffer and never holds the whole image in memory.

  • 02

    Save & load states

    Save a snapshot of the running machine to a .bin file you choose, then restore it later. Nothing is saved automatically.

  • 03

    Pause & resume

    Freeze the CPU at any moment. Disk writes are flushed when you pause.

  • 04

    RAM, your call

    Type the exact number of megabytes the VM gets, from 16 MB to 3 GB.

  • 05

    Fullscreen + keyboard lock

    Go fullscreen and keys like Esc, Alt+Tab and the Windows key go to the VM instead of your browser.

  • 06

    Swap drives

    Switch between images, or add a second disk and a CD-ROM. A swap does a clean restart on the new disk.

  • 07

    Real input

    Pointer-lock mouse, scancode-accurate keyboard, and a special-keys menu with Ctrl+Alt+Del.
